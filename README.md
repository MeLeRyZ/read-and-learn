# Read & Learn

Читалка немецких текстов: нажмите на слово, чтобы увидеть перевод, начальную форму и смысловой кусок фразы. Выделите несколько слов, чтобы перевести фразу целиком. Закладка сохраняет кусок в словарик, а словарик выгружается в CSV для Anki (две колонки: немецкий и перевод).

Переводы готовятся заранее, вручную и с учётом контекста. Сторонние сервисы перевода не используются, приложение работает офлайн.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/ (PWA)
npm test
```

## Как добавляется текст

1. `npm run text -- init <файл.srt|.txt> <id> "Заголовок"` разбивает текст на абзацы и пронумерованные предложения (`texts-src/<id>/source.txt`).
2. Разметка пишется в `texts-src/<id>/annot-*.txt` и `glossary-*.txt`. Формат описан в начале `scripts/text.ts`.
3. `npm run text -- build <id>` собирает `public/texts/<id>.json` и проверяет, что у каждого слова есть перевод, а куски и выражения совпадают с текстом.

Данные пользователя (словарик, место чтения) хранятся только в браузере (IndexedDB). На странице словарика есть резервная копия в JSON.
